About

안녕하세요. 사용자가 매일 쓰는 서비스의 속도와 안정성을 만드는 일에 보람을 느끼는 개발자 이서준입니다. 대학에서 소프트웨어공학을 전공한 뒤, IT 서비스 기업에서 웹 서비스 개발을 담당해 왔습니다.

React와 Node.js를 중심으로 프론트엔드·백엔드를 함께 다루며, 기능을 빠르게 내는 것만큼 읽기 쉬운 코드와 예측 가능한 배포를 중요하게 생각합니다. 제품 중심으로 기술을 쌓고, 팀 단위로 문제를 풀어 가는 환경에서 서비스 품질을 높이는 데 기여하고 싶습니다.

작업할 때는 장애와 성능 이슈의 원인을 끝까지 파고들고, 혼자만 아는 지식을 줄이기 위해 메모와 API 명세를 남깁니다. 생활신조는 “작게 배포하고, 빠르게 배우기”입니다. 안전한 범위에서 자주 배포하고, 측정과 회고로 다음 결정을 더 잘 내리는 개발자가 되고자 합니다.
